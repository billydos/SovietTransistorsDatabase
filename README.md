# SovietTransistorsDatabase - справочник советских транзисторов

Консольная утилита для ведения локальной базы справочника советских полупроводниковых приборов. Хранит структуру обозначения (ГОСТ 10862-64), электрические параметры с условиями измерения, предельные эксплуатационные данные и описательные атрибуты (проводимость, корпус, технология, производитель, годы выпуска и др.). База - SQLite (UTF-8), с заделом на будущий перенос на PostgreSQL/MariaDB.

Наполнение двумя способами: импортом из структурированного jsonc-файла или напрямую парсером обозначений.
## Возможности

- разбор обозначений: `КТ315Б`, `ГТ404А`, `2Т914А-1` (бескорпусное), `КТ825А1` (модификация), `1ТС801А` (сборка);
- 20 кодов электрических параметров (`h21e`, `FGran`, `KShum` с частотой, `PVyh`, `Kpd` и др.) с условиями и каноническими единицами;
- предельные данные, включая импульсные режимы, температуры и тепловое сопротивление;
- атрибуты: проводимость, корпус, цоколёвка, цветовая маркировка, ESD-чувствительность, военное исполнение, производители, годы выпуска;
- валидация и на уровне приложения, и на уровне БД (CHECK-ограничения), каскадное удаление, идемпотентный импорт.

## Быстрый старт

Требуется .NET 10 SDK (или установленный runtime для готового exe).

```shell
# сборка и проверка работоспособности
dotnet run --project SovietTransistorsDatabase -- parse КТ315Б

# наполнение базы из файла с примерами (20 транзисторов)
dotnet run --project SovietTransistorsDatabase -- import SovietTransistorsDatabase/sample-data.jsonc

# просмотр
dotnet run --project SovietTransistorsDatabase -- count
dotnet run --project SovietTransistorsDatabase -- list
dotnet run --project SovietTransistorsDatabase -- info КТ315Б
```

## Команды

| Команда | Назначение |
|---|---|
| `init` | создать таблицы (выполняется и автоматически) |
| `import <файл.jsonc>` | импорт транзисторов со всеми данными |
| `add <обозначение>...` | добавить транзисторы по обозначению (через парсер) |
| `parse <обозначение>...` | разобрать обозначение без обращения к базе |
| `list [фильтры]` | список обозначений; фильтры: `--material=Г`, `--subclass=П`, `--letters=АМ`, `--limit=N` и др. |
| `info <обозначение>` | полная карточка: атрибуты, параметры, предельные данные |
| `find <обозначение>` | проверить наличие (учитывает равнозначность Г/1, К/2...) |
| `delete <обозначение>...` | удалить записи (каскадно с данными) |
| `count` | количество записей |

Общие опции: `--db <путь>` - файл базы (по умолчанию `./transistors.db` или переменная `TRANSISTOR_DB`), `--dry-run` - проверка без записи.

Примеры:

```shell
dotnet run --project SovietTransistorsDatabase -- add ГТ404А КП303Е
dotnet run --project SovietTransistorsDatabase -- list --material=1 --subclass=Т
dotnet run --project SovietTransistorsDatabase -- info 2Т914А-1
dotnet run --project SovietTransistorsDatabase -- find 1Т402Ж
```

## Формат jsonc

Корень - объект с массивом `transistors`. Запись - строка, объект с `name` или объект с явными полями обозначения. Секции `attributes`, `parameters`, `ratings` необязательны: отсутствует - не меняется, задана - заменяется целиком.

```jsonc
{
  "transistors": [
    // 1) только обозначение
    "КТ315А",

    // 2) полное описание
    {
      "name": "КТ315Б",
      "attributes": {
        "structure": "npn", "technology": "планарная",
        "package": "КТ-13", "packageMaterial": "пластик", "pinout": "КБЭ",
        "yearFrom": 1967, "yearTo": 1992,
        "manufacturers": ["Восход", "Терма"]
      },
      "parameters": [
        { "parameter": "h21e",  "min": 50, "max": 350, "Uke": 10, "Ik": 1 },
        { "parameter": "FGran", "min": 250, "Uke": 10, "Ik": 5 },
        // один параметр при двух температурах - две строки
        { "parameter": "Ikbo", "max": 0.5, "Ukb": 10, "temp": 25 },
        { "parameter": "Ikbo", "max": 5,   "Ukb": 10, "temp": 85 }
      ],
      "ratings": { "UkeMax": 20, "UkeoMax": 15, "IkMax": 100, "PkMax": 150, "tempMin": -60, "tempMax": 125 }
    },

    // 3) обозначение явными полями
    {
      "material": "Г", "subclass": "Т", "feature": 1,
      "number": 15, "letters": "А",
      "attributes": { "structure": "pnp" },
      "parameters": [
        // условия включения с общей базой: пара Ukb + Ie
        { "parameter": "h21e", "min": 30, "max": 90, "Ukb": 5, "Ie": 1 }
      ]
    },

    // 4) частотные параметры: freq обязательна
    {
      "name": "КТ3102А",
      "parameters": [
        // коэффициент шума: 1 кГц = 0.001 МГц, Rg - сопротивление генератора
        { "parameter": "KShum", "max": 10, "Uke": 5, "Ik": 0.2, "freq": 0.001, "Rg": 200 }
      ]
    },

    // 5) СВЧ-генераторные параметры и бескорпусное исполнение
    {
      "name": "2Т914А-1",
      "parameters": [
        { "parameter": "PVyh", "min": 3, "freq": 1000 },
        { "parameter": "Kpd",  "min": 40, "Uke": 15, "Ik": 100, "freq": 1000 }
      ],
      "ratings": { "UkeMax": 30, "IkMax": 300, "PkMax": 3000, "tempMin": -60, "tempMax": 125 }
    }
  ]
}
```

Полный справочник кодов параметров, правил условий, единиц измерения и полей секций:

```shell
dotnet run --project SovietTransistorsDatabase -- help
```

а также файл `SovietTransistorsDatabase/sample-data.jsonc` (полный пример) и регламент `.kilo/skills/soviet-transistors/SKILL.md`.

## Сборка и публикация

```shell
dotnet build SovietTransistorsDatabase/SovietTransistorsDatabase.csproj -c Release

# один exe (требует установленного .NET runtime)
dotnet publish SovietTransistorsDatabase/SovietTransistorsDatabase.csproj -c Release -r win-x64 `
  --self-contained false -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true -o publish-single
```

## Структура проекта

```
SovietTransistorsDatabase/
  Program.cs                  CLI
  Domain/                     обозначения, параметры, ratings, атрибуты, валидация
  Data/                       реляционное ядро + SQLite (DDL, DML)
  Import/                     чтение jsonc
  sample-data.jsonc           пример наполнения (20 транзисторов)
```
